# دليل مدير النظام — منصة إمبراطور (Emperor Admin Manual)

هذا الدليل مخصص لمديري العمليات والمشرفين على منصة **إمبراطور** لإدارة العمليات المالية والكتالوج وتوزيع التارجت ومتابعة المزودين.

---

## 1. الوصول للوحة التحكم (Filament Admin Panel)
- **الرابط:** `https://emperor.vip/admin`
- **الحساب الافتراضي:** `admin@emperor.vip`
- **التصميم:** واجهة عربية RTL ملكية تدعم الوضع المظلم (Dark Mode) بالكامل مع درجات اللون الذهبي والأسود الملكي.

---

## 2. إدارة العمليات المالية والمحفظة

### أ. مراجعة وتأكيد طلبات الإيداع (Deposit Requests)
1. الدخول إلى: **العمليات المالية > طلبات الإيداع**.
2. تظهر الطلبات بحالة **"قيد المراجعة" (Pending)** باللون البرتقالي مع صورة إيصال التحويل والبيانات.
3. الضغط على زر **"معاينة الإيصال"** للتأكد من المرجع وقيمة التحويل.
4. عند الضغط على **"موافقة واعتماد" (Approve)**:
   - يتم شحن رصيد محفظة العميل فورياً بعملة الحساب.
   - يتم تسجيل العملية في دفتر الأستاذ المالي (Ledger).
   - يتم صرف عمولة الإحالة التلقائية في محفظة الداعي (Referrer) إن وجد.
   - يتم إرسال إشعار لحظي للعميل عبر **WhatsApp** وإشعار **Push**.
5. عند الضغط على **"رفض" (Reject)**:
   - يلزم إدخال سبب الرفض باللغة العربية (مثل: "رقم الحوالة غير صحيح").
   - يصل التنبيه بالسبب فورياً للعميل.

---

## 3. إدارة بيع واستلام التارجت (Target Selling)
1. الدخول إلى: **التارجت > تطبيقات التارجت والأسعار**.
2. يمكنك تعديل أسعار الشراء (EGP per Point) لكل تطبيق (Likee, TikTok, Bigo, etc.) ومعرف الوكالة (Agency ID).
3. مراجعة الطلبات الواردة في **طلبات استلام التارجت**:
   - التحقق من صورة الإثبات ومعرف المستخدم في التطبيق.
   - عند الموافقة يتم إيداع المقابل المالي في محفظة العميل فورياً.

---

## 4. إدارة الكتالوج وباقات الشحن (Catalog & Products)
1. **الأقسام:** إضافة أقسام جديدة (ألعاب، برامج شات صوتي، بطاقات رقمية).
2. **المنتجات:** ضبط حقول الإدخال الإلزامية للعميل (مثل: Player ID, Server ID, Region).
3. **الباقات والأسعار (Product Tiers):**
   - تحديد تكلفة الشراء من المورد (`source_cost`).
   - اختيار استراتيجية التسعير (نسبة ربح مئوية %، هامش ربح ثابت، أو تسعير يدوي مخصص).

---

## 5. مزودو الخدمة والتنفيذ الآلي (Providers & Cascade Routing)
1. الدخول إلى: **الإعدادات والمزودين > مزودو الخدمة**.
2. ضبط أولوية التنفيذ (`Priority`):
   - يتم توجيه الطلب للمزود رقم `1` (مثل: مزود هلا أو طامي).
   - في حال حدوث عطل أو نقص في رصيد المزود، يقوم النظام تلقائياً بتمرير الطلب للمزود رقم `2` (Cascade Fallback).
3. فحص الأرصدة الحية لدى المزودين مباشرة من شاشة العرض.

---

## 6. عملاء الـ API والتجار الخارجيين (B2B Merchants)
1. توليد مفاتيح الوصول (`API Key` و `API Secret`).
2. تحديد قائمة الـ IP البيضاء (`IP Whitelist`) لمنع الاختراق.
3. تخصيص جدول أسعار خاص بالتاجر (Pricing Matrix) أقل من سعر الجمهور.
4. متابعة سجلات الـ API والويبهوكات عبر شاشة **سجلات الربط (API Logs)**.
